# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。

# 调休反例

每位员工10月1日假日段22:00-24:00为2小时可调休时数（HOLIDAY），其余为REGULAR不形成。E001申请2小时已批准且该班已实发220元：裁决保住调休余额120分钟，假日段重复工资120元记待追回。E002申请5小时只批准2小时，超出3小时挡下。E003申请1.5小时待批，不进余额。E004时长abc、E005状态已到账、E006同班两份不一致申请分别挡下。若把E001进卡改为21:00（版本2），假日段变为3小时，工资与调休余额同批一起重算。
